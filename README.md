
INSURANCE COST PREDICTOR
=======================

A Machine Learning Web Application that predicts medical insurance charges using Linear Regression and Streamlit.

LIVE APPLICATION
================

App Link:
https://machine-learning-day-1-o44w9jefmrcvev8fzpoume.streamlit.app/

PROJECT FEATURES
================

1. Predict insurance charges using Machine Learning.
2. Enter customer age and gender.
3. Enter BMI (Body Mass Index).
4. Select number of children.
5. Select smoking status.
6. Select customer region.
7. Display predicted insurance charges.
8. Interactive web application using Streamlit.

TECHNOLOGIES USED
=================

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Joblib
- Google Colab
- GitHub

MACHINE LEARNING ALGORITHM
==========================

Linear Regression

PROJECT WORKFLOW
================

1. Import the insurance dataset.
2. Explore and analyze the dataset.
3. Check missing values.
4. Check and remove duplicate records.
5. Handle missing numerical and categorical values.
6. Encode categorical variables using One-Hot Encoding.
7. Split the dataset into training and testing data.
8. Standardize numerical features using StandardScaler.
9. Train the Linear Regression model.
10. Predict insurance charges.
11. Evaluate model performance using:
    - Mean Absolute Error (MAE)
    - Mean Squared Error (MSE)
    - Root Mean Squared Error (RMSE)
    - R2 Score
12. Save the trained model using Joblib.
13. Build the web application using Streamlit.
14. Deploy the application using Streamlit Community Cloud.

HOW TO RUN THE PROJECT
======================

1. Clone the GitHub repository.

2. Install the required libraries:

   pip install -r requirements.txt

3. Run the Streamlit application:

   streamlit run app.py

4. Open the local URL in your browser.

PREDICTION INPUTS
=================

- Age
- Gender
- BMI
- Number of Children
- Smoking Status
- Region

OUTPUT
======

The application predicts the estimated insurance charges based on the customer details entered by the user.

IMPORTANT NOTE
==============

The predicted amount is an estimate generated by a Machine Learning model. It is not an actual insurance quotation or guarantee.

The prediction uses the same currency and units as the original dataset's charges column.
